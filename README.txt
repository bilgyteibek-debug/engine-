ENGINE MAKER 1.0 - ANDROID PROJECT

This project wraps your existing engine.html in a fullscreen Android WebView app.

IMPORTANT
- The Three.js library is loaded from cdnjs.cloudflare.com, so the first version needs an internet connection to display the 3D engine.
- Sound is generated by Web Audio and should be enabled by tapping the in-game sound button.
- This folder is Android source code, not a built APK yet.

BUILD ON ANDROID PHONE
1. Install AndroidIDE (Android IDE) from its official project source / supported distribution. Be careful to use a trustworthy source.
2. Extract this ZIP to a folder on internal storage.
3. In AndroidIDE, open/import the extracted EngineMaker project folder.
4. Allow it to download Gradle/Android build components if prompted. This may take time and data.
5. Run the Gradle task :app:assembleDebug, or use the app's Build/Run action.
6. The debug APK should be created at app/build/outputs/apk/debug/app-debug.apk.
7. Install the APK and allow Android to install apps from that source if prompted.

If AndroidIDE does not support this Gradle/Android plugin version, the project may need its supported plugin version adjusted. You can also open the folder in Android Studio on a computer.
